# AI guide

Guidance the AI agents (and humans) build against. These sit alongside the
product specs in this directory. When code and these docs disagree, fix one of
them — never silently diverge.

Start at `../AGENTS.md`: it is the entry point for every coding agent and the
source of truth for the operating rules. The files below are the depth behind it.

- `ARCHITECTURE.md` — layering, module ownership, event flow.
- `SAFETY.md` — the non-negotiable safety rules.
- `CONVENTIONS.md` — code + workspace conventions.
- `SPRINT_1_FOUNDATION.md` — Sprint 01 scope, status, and definition of done.
  Historical record, not a source of work (`AGENTS.md` §4.3).
- `plans/ROADMAP.md` — authoritative sprint numbering and sequence.
