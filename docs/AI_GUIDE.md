# docs-ai

Guidance the AI agents (and humans) build against. These mirror and extend the
product specs in `../docs`. When code and these docs disagree, fix one of them —
never silently diverge.

- `ARCHITECTURE.md` — layering, module ownership, event flow.
- `SAFETY.md` — the non-negotiable safety rules.
- `CONVENTIONS.md` — code + workspace conventions.
- `SPRINT_1_FOUNDATION.md` — Sprint 1 scope, status, and definition of done.
