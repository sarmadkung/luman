# Product Spec

## Product
A macOS storage intelligence application.

## Target Users
1. Developers
2. Power users
3. Creators

## Core Value
Help users understand storage, safely reclaim space, and explain why cleanup is safe.

## Non Goals
- Antivirus
- RAM cleaner
- Fake performance optimization

## Global Business Rules
- Scans are read-only.
- Cleanup is explicit.
- AI never performs destructive actions.
